# Guided Every Open setup

Implemented 8 November 2026 on `feat/guided-shortcut-setup`, based on main `047596f` (app version 2.2.0).

## User flow

Settings → App protection offers one learning-frequency choice. Every Open opens the guided setup; timed access keeps the existing Screen Time flow. Choosing a display option does not silently disable active protection.

1. **Choose X → Set up in Apple Shortcuts.** Veea prepares the selected app, Every Open learning rule and a fresh verification attempt before opening Apple's installer. It preserves other selected apps and learning choices. If timed native protection is active, the screen explains the switch before the user continues.
2. **Approve in Apple’s import flow.** Turn on **Automation** and tap **Add Shortcut**. The template includes a trigger setup question (`Category: Trigger`, `ParameterKey: __enabled__`, matching `TriggerUUID`) so the switch appears during import. No separate visit to the Automation library and no action assembly are required. First-run system confirmations remain Apple's UI.

An optional **Test: open X** button repairs or verifies existing installations. It clears X's old earned pass without discarding unfinished vocabulary progress, starts a fresh verification attempt, and opens X. Import cancellation leaves setup unverified; users can retry. Keep only one enabled X automation if Apple offers to keep multiple copies.

Opening an installer or returning from Shortcuts never marks setup successful. Check Veea Gate records a pending test only for the correct selected app, with Shortcut protection enabled, native protection off and the test less than five minutes old. A random nonce ties the result to the latest attempt. The app says **Test successful**, rather than claiming it can inspect Apple's automation switch. Review/retest is available. External automation changes need a new test.

App-open triggers may not run through Mirroring; the guide asks users to test from their physical iPhone's Home Screen.

## Template and scope

- X installer: <https://www.icloud.com/shortcuts/d46f1dd0603a4c09a05fa9a12dd43d3e>
- X bundle ID: `com.atebits.Tweetie2`; Veea intent: `com.nintran.veeaEnglishApp.CheckVeeaGateIntent`, team `9X6SFG9KXM`.
- The four actions are background Check Veea Gate, If true, Open `veea://gate?app=X`, End If. There is no unconditional Open URL after the If.
- Source and Apple-signed export are in `assets/shortcuts/` for review/recovery. The installer uses the stable iCloud link, not a temporary download URL. Run `python3 tool/test_shortcut_template.py` to verify the source and signed export checksum.
- **The ready-made catalog currently contains X only and requires iOS 27+.** Other existing apps/automations stay under Manage existing shortcuts. Do not reuse X's template for another app. Additional apps need their own exported template, matching parameter/trigger/link and a physical-device test.
- Templates reference the production/TestFlight bundle ID. A separate personal-profile app with a different ID needs a matching template.
- The dependency lockfile was regenerated by Flutter 3.44.6 / Dart 3.12.2 within the existing declared dependency ranges. No dependency constraints were changed.
