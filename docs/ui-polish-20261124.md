# UI polish for the first customer release

24 November 2026. Based on free-first launch commit `928283b` and kept in the
same draft launch-readiness PR. No phone installation, signed build, TestFlight
upload or production submission was performed by this UI work.

## Result

- Retained the existing blue/white Material design and made its typography,
  grouped rows, sheets, fields and dark-mode borders consistent. Unboxed toolbar
  icons and quieter shadows reduce visual clutter without adding dependencies.
- Notebook: clearer title, compact calendar selector, readable IPA on its own
  line, larger headwords, lower-priority metadata and a compact inline Add word
  button. Review count uses an informational blue badge. Listen/Review actions
  expose semantic tap actions; destinations use MaterialPageRoute rather than
  a zero-duration custom route.
- Listen: removed the large decorative cassette and animation. The playlist,
  Choose words action and current word now lead. Settings stays behind its
  button/sheet. Five transport controls remain, with prominent Play/Pause.
  Narrow/large-text headers omit decorative artwork; text scaling is preserved.
- Review: removed duplicate progress, simplified flashcards and revealed meaning,
  formatted IPA consistently and made all four recall ratings equally outlined.
  Removed duplicate completion statistics. Keyboard shortcuts, SRS mappings,
  submission guard and failure recovery remain intact.
- Editor: readable sentence-case headers, multiline meaning, accessible rounded
  part-of-speech chips and a secondary delete action. Renamed the local template
  generator to Example ideas rather than implying a remote AI service.
- Settings: preserved Learning rules and app-lock controls; grouped notebook
  options ahead of optional account controls, aligned headings and simplified
  informational notices. Existing destinations and stable keys remain.

Free-first capability, privacy consent, duplicate-word detection, local notebook
ownership, Screen Time timer/toggle logic and backend/payment contracts were not
changed. Widgets, Arcade and Every Open setup remain hidden as before.

## Coordination and independent review

Actual agy CLI implemented Listen and Review within those two source files and
returned its decisions/risks. Actual Claude CLI reviewed the source and readable
light/dark PNGs. Root addressed its five medium findings: revealed-card corner
radius, IPA formatting, Settings hierarchy/alignment, More details padding and
calendar semantics including the selected date. Claude's final check found no
remaining blocker or medium issue. Claude did not execute tests or device QA;
root ran the checks below.

The review follows [Apple's layout guidance](https://developer.apple.com/design/human-interface-guidelines/layout)
on hierarchy, grouping and adaptable content, while retaining the existing
Flutter Material implementation. This is a refinement, not a platform rewrite.
